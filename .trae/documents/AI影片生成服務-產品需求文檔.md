# AI 影片生成服務 - 產品需求文檔

## 1. Product Overview

本產品是一個基於 Golang 開發的 AI 影片生成後端服務，接收包含圖片、字幕和提示詞的 JSON 請求，調用外部 AI 服務生成影片並添加字幕後回傳。

* 解決問題：自動化影片生成流程，將靜態圖片轉換為帶字幕的動態影片內容

* 目標用戶：需要批量生成影片內容的開發者和內容創作平台

* 產品價值：提供簡單易用的 API 接口，實現圖片到影片的自動化轉換，大幅提升內容生產效率

## 2. Core Features

### 2.1 Feature Module

我們的 AI 影片生成服務包含以下核心功能模組：

1. **任務接收 API**：接收影片生成任務請求，包含圖片路徑、字幕資訊和生成提示詞
2. **任務狀態管理**：追蹤和管理影片生成任務的執行狀態
3. **AI 影片生成**：調用外部 AI 服務將圖片轉換為影片
4. **字幕處理**：在生成的影片上添加指定的字幕內容
5. **影片回傳 API**：將完成的影片檔案上傳回指定的端點

## 3. Core Process

### 主要業務流程

1. **任務接收階段**：外部系統發送 POST 請求到服務端點，包含任務 ID、圖片路徑、字幕資訊和生成提示詞
2. **任務處理階段**：服務驗證請求資料，創建內部任務記錄，立即回傳 pending 狀態給調用方
3. **影片生成階段**：後台異步處理任務，下載圖片檔案，調用外部 AI 服務生成基礎影片
4. **字幕添加階段**：在生成的影片上根據指定參數添加字幕內容
5. **結果回傳階段**：將完成的影片檔案上傳到指定的回調端點，更新任務狀態為 completed

## 4. User Interface Design

### 4.1 Design Style

由於本產品為後端 API 服務，不涉及前端界面設計。主要關注點在於：

* **API 回應格式**：統一的 JSON 格式，包含 status、message、data 等標準欄位

* **錯誤處理**：清晰的錯誤代碼和描述訊息

* **日誌格式**：結構化日誌輸出，便於監控和除錯

* **文檔風格**：清晰的 API 文檔和使用範例

### 4.2 API Response Design

| API 端點               | 回應格式 | 主要欄位                                                            |
| -------------------- | ---- | --------------------------------------------------------------- |
| POST /generate-video | JSON | status (string), external\_id (string), message (string)        |
| 錯誤回應                 | JSON | error\_code (string), error\_message (string), details (object) |
| 成功回應                 | JSON | success (boolean), message (string), data (object)              |

### 4.3 Responsiveness

本服務為純後端 API，不涉及響應式設計。重點關注：

* **API 回應時間**：任務接收 API 需在 500ms 內回應

* **併發處理**：支援多個任務同時處理

* **錯誤恢復**：具備重試機制和失敗處理能力
