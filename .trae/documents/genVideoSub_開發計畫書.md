# genVideo&Sub 開發計畫書

## 1. 專案概述

本專案採用輕量化架構，使用Streamlit前端 + Golang後端 + fal.ai API集成的技術方案，實現AI視頻生成服務。專案目標是提供零依賴、易部署的解決方案，支援大文件異步處理和批量任務管理。

## 2. 專案階段規劃

### 階段一：基礎架構搭建 (Week 1-2)
- 建立專案目錄結構
- 配置Golang開發環境
- 建立基礎API框架
- 實現內存存儲和JSON持久化
- 建立基礎Streamlit界面

### 階段二：核心功能開發 (Week 3-4)
- 實現任務管理API
- 集成fal.ai API客戶端
- 開發文件上傳和處理功能
- 實現異步任務處理機制
- 建立Goroutine Pool並發管理

### 階段三：前端界面完善 (Week 5)
- 完善Streamlit用戶界面
- 實現實時狀態顯示
- 添加批量處理功能

### 階段四：測試與優化 (Week 6)
- 單元測試和集成測試

## 3. 技術實現步驟

### 3.1 後端開發 (Golang)

#### 步驟1：專案初始化
```bash
# 初始化Go模組
go mod init genVideoSub

# 安裝必要依賴
go get github.com/gin-gonic/gin
go get github.com/google/uuid
go get github.com/sirupsen/logrus
```

#### 步驟2：目錄結構
```
backend/
├── main.go
├── config/
│   └── config.go
├── handlers/
│   ├── task.go
│   └── health.go
├── services/
│   ├── task_service.go
│   ├── fal_service.go
│   └── file_service.go
├── models/
│   └── task.go
├── storage/
│   ├── memory.go
│   └── json.go
├── utils/
│   └── worker_pool.go
└── data/
    ├── tasks.json
    └── temp_files.json
```

#### 步驟3：核心功能實現
1. **任務管理**：創建、查詢、更新任務狀態
2. **fal.ai集成**：API客戶端、請求處理、錯誤重試
3. **文件處理**：上傳、下載、臨時存儲、清理
4. **並發處理**：Goroutine Pool、Channel隊列
5. **數據持久化**：內存存儲、JSON備份

### 3.2 前端開發 (Streamlit)

#### 步驟1：環境設置
```bash
# 安裝Streamlit
pip install streamlit requests
```

#### 步驟2：界面結構
```
frontend/
├── app.py
├── components/
│   ├── file_uploader.py
│   ├── task_status.py
│   └── config_panel.py
├── utils/
│   └── api_client.py
└── requirements.txt
```

#### 步驟3：功能實現
1. **文件上傳**：多文件選擇、預覽、驗證
2. **參數配置**：字幕設置、顏色選擇、位置配置
3. **任務管理**：提交任務、狀態查詢、結果下載
4. **批量處理**：並發上傳、進度顯示、批量下載
